# 校园网登录

macOS 13+ 校园网认证工具，支持本机 Mac 和通过 SSH 连接的服务器，适配苏州大学 Dr.COM 认证页面。

支持独立账号和运营商设置、钥匙串保存密码、密码显示切换、服务器拖动排序与删除、自定义分钟间隔自动检查，以及菜单栏暂停和恢复。

## 构建

安装 Xcode Command Line Tools 后执行：

```sh
./build.sh
```

DMG 安装包位于 `dist/Campus Login.dmg`。应用在临时目录中构建并封装，结束后自动清理，包含 Apple Silicon 和 Intel 架构，采用本地临时签名。

## 使用

远程设备从 `~/.ssh/config` 的具体 Host 配置中选择，需先在终端完成主机密钥确认及 SSH 密钥认证。本机模式无需 SSH。执行认证的设备需要 python3 和 curl。

自动检查依赖应用运行，Mac 休眠时暂停。校园网认证过期后可自动登录；Wi-Fi 断开或 SSH 不可达时需要恢复连接。首次读取钥匙串或重新构建后，系统可能要求授权。

账号配置保存在应用偏好设置中，密码保存在本机钥匙串。源码仓库不包含用户配置或密码。

卸载前，在应用菜单或菜单栏图标中选择「清除全部数据并退出…」，确认后会删除设备配置和本应用的钥匙串密码。随后将应用移到废纸篓。

DMG 默认窗口为 760 × 508 点，图标为 128 点，包含安装箭头和提示。首次构建会在本地 .build/dmg-tools 创建 Python 环境并安装锁定版本的 ds-store/mac-alias，用于生成 Finder 布局。

本机模式可开启「自动连接 SUDA_WIFI」。登录和定时检查会先连接该 Wi-Fi 并等待 IPv4 地址，再检查校园网认证。此功能默认关闭，识别网络需要 macOS 定位权限，Wi-Fi 必须开启且网络在范围内。

开启「自动连接 SUDA_WIFI」和定时检查后，可以另行开启「认证网关超时后重连 SUDA_WIFI」。本机连续两轮自动检查确认认证网关超时后，会重新连接 SUDA_WIFI 并检查是否需要登录。每 5 分钟最多尝试一次，账号认证被拒绝时不会触发重连。
